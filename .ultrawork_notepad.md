- Workspace: uv project with only `pymupdf` declared; `.venv` empty; no PDFs locally; precomputed `chunks (2).json` (2,132 chunks from GINA + NHLBI) is reusable.
- Additional authoritative resources (HTTP-verified): WHO 2026 pediatric asthma guideline (CC BY-NC-SA), NICE NG245 (2024), BTS/SIGN SIGN 158, ATS/ERS severe asthma guideline (2014 PDF + 2020 ERJ), Global Asthma Report 2022 (all rights reserved — cite only), NHLBI 2020 focused updates.
- Recommended default inhaler video: American Lung Association “Mastering Your Inhaler: Step-by-Step to Using a Spacer with a Metered-Dose Inhaler” (YouTube ID `TuzCfpeieFA`), embeddable via `gr.HTML` iframe.
- Tech stack (current APIs):
  - Groq: `groq` client, `client.chat.completions.create`, free-tier models incl. `llama-3.3-70b-versatile`; `mixtral-8x7b-32768` deprecated.
  - Cohere: `cohere.ClientV2`, `co.rerank(model="rerank-v4.0-pro", ...)`, map results via `result.index`.
  - Local embedding: `Qwen/Qwen3-Embedding-0.6B` via `SentenceTransformerEmbeddingFunction`; needs `transformers>=4.51.0`, `chromadb>=0.5.0` for kwargs passthrough; ~1.2 GB download, CPU feasible.
  - Gradio video: canonical is `gr.HTML` with YouTube iframe; `gr.Video` does NOT support YouTube watch URLs.
  - Agentic RAG: LangGraph pattern with `generate_query_or_respond → retrieve → grade_documents → generate_answer/rewrite_question`.

## Learnings
- Do not commit copyrighted PDFs; keep a `sources.yaml` with URLs + license notes and a downloader that respects restrictions.
- Centralize config (paths, keys, model names, top-k/threshold) before any pipeline code; this fixes most Colab-to-local migration issues.
- Use `prompt_name="query"` for Qwen3 query embeddings; document embeddings get no prompt.
- Real runs catch what unit tests miss: (1) package was never installed → `python -m` commands failed; (2) `llama-3.3-70b-versatile` is retired on Groq; (3) query-time embeddings must match index-time embeddings or Chroma throws a dimension mismatch; (4) Chroma persists the embedding-function config, so a stale collection conflicts on re-index — delete at client level before rebuilding; (5) real PDFs produce `section_title=None`, which Chroma's metadata rejects — coerce to "" at the vectorstore boundary; (6) Windows cp1252 consoles cannot print Unicode LLM output — reconfigure stdout to UTF-8.
- Ollama GPU (`qwen3-embedding:0.6b` via `/api/embed`) embeds 64 texts in ~1s warm; the full 2,257-chunk index builds in ~36s vs hours on CPU.
